# v0.0.3

> 这是给 GitHub Release 正文用的草稿。发布时把下面的 `sha256` 换成 `dist\SHA256SUMS.txt` 里那一条。

**把 DSH 变成 Windows 桌面**：壁纸上方的时间 / 日期 / 手写文字 / 天气 / fps 挂件层，在 DSH 自己的设置窗口里可调；点桌面上的输入框就能直接打字，点到别处会把键盘和焦点还回去。

由两半组成，**只装插件不够**：

- **插件**（`dsh-plugin-desktop-mode`）：页面里的挂件层、打字触发、设置页，以及调用原生工具的路由；
- **原生宿主包**（本 Release 的 zip）：把窗口钉进 Explorer 桌面、隐藏图标、离开/回到桌面层接管键盘、开机自启、托盘。

## 安装

1. 下载 `dsh-desktop-mode-v0.0.3.zip` 并解压；
2. 进入 `host\` 子目录，双击 `install.cmd`（或 `pwsh -File host\install.ps1`）；
   - 安装器会自己找你的 DSH 桌面端；找不到就用 `-ShellExe "<exe 路径>"` 指定；
   - 装到 `%LOCALAPPDATA%\dsh-desktop-mode`，注册插件与开机自启，然后立即启动；
3. 桌面随即变成 DSH。

卸载：`host\uninstall.cmd`（会保留你的挂件配置成 `widgets.json.bak`）。

**校验下载**：

```powershell
Get-FileHash .\dsh-desktop-mode-v0.0.3.zip -Algorithm SHA256
# 与 SHA256SUMS.txt 里的值一致
sha256 = <发布时填入>
```

## 这个版本有什么

**新增：设置页进了 DSH 的设置窗口。** 侧栏「设置」最下面多一页**「桌面挂件」**（总开关 / 时间 / 颜色与取色 / 手写文字 / 右上角信息 / 天气 / 角色立绘，共 7 组 44 项）。保存后挂件立刻重画，**不用刷新页面**；直接手改 `widgets.json` 也一样，最多 3 秒自动生效。

**新增：打字会把键盘和焦点还回去。** 点桌面输入框 → 拿到键盘 → `Esc` 或点到别处 → 回到桌面层，**并且焦点回到你原来在用的那个窗口**（以前会留在桌面上）。

**新增：发行门禁。** `packaging/verify-release.ps1` 解包核对 16 项：校验和与 zip 一致、安装器/启动器需要的文件齐全、没有任何私有内容或私人路径、包里每个脚本都能解析、**包内那份配置校验逻辑仍然满足契约**、两个安装器都能真跑一遍（`-WhatIf`）。

**修复**（都来自两轮独立评审）：

- 安装后插件找不到原生工具（安装器放在 `tools\bin\`，插件却在安装根找）⇒ 干净安装上打字永不生效；
- 启动器读错挂件配置路径，导致"挂件层没挂上"的守卫是死代码、启动假成功；
- 托盘「重载挂件」驱动的是早就跑不起来的旧注入器 ⇒ 改为驱动插件；
- 打字失败时状态机会卡住，之后再也不会尝试回到桌面层；
- 页面版本号与实际包版本不一致（硬编码）；
- 插件路由不受实例令牌保护 ⇒ 写路由现在要求随包客户端头 + 回环 Host（**注意：这不是身份认证，挡不住本机进程**）；
- 托盘图标原本与第三方桌面 App 的图标逐字节相同 ⇒ 换成自制图标；
- 安装器在 `-FromLocal` 下把插件链接到解包目录（删掉压缩包就断）⇒ 改为链接安装目录里的副本；
- 启动时页面渲染检查超时会摘掉一个健康的层 ⇒ 改为只警告。

## 要求

- **Windows 10/11**；
- 一个 DSH 桌面端（官方桌面端 / DSH Desktop ≥ 2.0.7 / 壁纸插件的桌面版都可以）；
- 可选：`dsh-plugin-wallpaper-engine`（不装就是纯色背景 + 挂件）。

## 已知限制

- 桌面上打字必须**临时离开桌面层**（Windows 不允许桌面子窗口成为前台窗口），切换期间用冻屏遮罩盖住 1–2 帧；这是机制决定的，不是 bug。
- 挂件配置不进 Cordis 配置层，因此 `dsh --dump-config` 里看不到它（这是有意的：它能活过插件升级）。
- 启动器读页面状态依赖调试端口 9222（插件本身不需要它）。
- 首次启动时外壳要加载约 70 个插件 bundle，可能几分钟才渲染完；启动器会等并如实报告。
